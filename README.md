# RaycastPM

RaycastPM 是一个 Windows 桌面效率工具，常驻系统托盘，通过快捷键快速打开导航、剪贴板、记事本、设置和实时监控。

它适合用来：

- 快速搜索并打开本机应用、文件和文件夹
- 临时计算表达式或换算汇率
- 记录和搜索剪贴板历史
- 快速写记事和保存图片附件
- 查看实时网速、CPU、GPU 和内存占用

开发和构建说明见：[开发者说明](docs/developer-guide.md)。

## 快速使用

启动应用后，RaycastPM 会留在系统托盘中。可以通过托盘右键菜单打开各个功能，也可以使用默认快捷键：

```text
导航：Ctrl + Alt + Space
剪贴板：Ctrl + Alt + V
记事本：Ctrl + Alt + N
设置：Ctrl + Alt + S
```

快捷键可以在设置页中修改，并会立即保存。

## 导航搜索

导航栏可以搜索本机应用、文件和文件夹，也支持计算和汇率换算。

搜索结果的基本排序规则：

- 应用优先展示
- 文件优先于文件夹
- 文件和文件夹优先按名称匹配
- 使用次数越多，排序越靠前

首次使用时，RaycastPM 会先加载应用缓存，让应用搜索尽快可用；完整文件/文件夹索引会在后台加载或重建，不会阻塞主界面。

更多搜索写法见：[导航搜索规则](docs/navigation-search-rules.md)。

## 剪贴板

剪贴板会记录文本、图片、文件、链接和颜色历史，支持搜索、分类筛选、删除和复制。

常用操作：

- 双击历史项会复制该内容
- 从剪贴板窗口复制后会自动隐藏窗口
- 会尽量切回打开剪贴板前的窗口
- 会自动发送 `Ctrl+V` 完成粘贴
- 文件类记录复制回去时会尽量还原为系统文件剪贴板

剪贴板历史最多保留 120 条。

## 记事本

记事本用于快速记录内容，支持：

- 新建和删除记事
- 搜索历史记事
- 标题和正文自动保存
- 调整字号
- 添加图片附件
- 从剪贴板粘贴图片

记事本不会像导航和剪贴板一样自动隐藏，方便长时间编辑。

## 实时监控

可以在设置页开启实时监控小条。开启后会显示：

- 实时下载/上传速度
- CPU 使用率
- GPU 使用率
- 内存使用率

监控小条会置顶显示；关闭设置或隐藏小条后会停止采样，减少后台占用。

## 设置

设置页提供：

- 重新扫描硬盘索引
- 清除导航缓存数据，清除前需要二次确认
- 清空导航使用统计
- 开启或关闭 Windows 开机自启
- 开启或关闭日志输出，并选择日志目录
- 开启或关闭实时监控
- 修改记事本字号
- 查看数据目录
- 可视化编辑全局快捷键

## 后台待机

主窗口隐藏到托盘后，RaycastPM 会暂停不需要持续运行的内容，例如索引进度 UI 刷新、导航搜索任务和汇率定时刷新。

仍会保留必要能力：

- 全局快捷键
- 托盘入口
- 剪贴板历史监听
- 文件系统增量监听

如果实时监控小条仍然显示，它会继续保持实时采样；小条隐藏后采样会暂停。

## 本地数据

应用数据默认保存在：

```text
%AppData%\RaycastPM
```

主要数据包括：

- 应用设置
- 剪贴板历史
- 记事内容
- 导航使用次数
- 导航索引缓存
- 可选日志文件
